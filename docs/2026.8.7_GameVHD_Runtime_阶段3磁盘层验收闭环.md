## 2. 关键技术定案（真机验证后修订）

### 2.1 盘符分配 API：DefineDosDevice → SetVolumeMountPoint

**初版偏差**：v2 定案 §3.2 字面写 `DefineDosDevice`——返回"成功"但文件资源管理器看不到盘符，且写 `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\DOS Devices` 注册表残留（E/F/G 键）。

**文档依据**（CreateFile/DefineDosDevice 文档 Remarks）：
> "To define a drive letter assignment that is persistent across boots and not a network share, use the **`SetVolumeMountPoint`** function."

**定案**：
- 给卷分配盘符 = `SetVolumeMountPointW("E:\\", "\\?\Volume{GUID}\\")`（挂载点、卷名均带尾反斜杠）
- 移除 = `DeleteVolumeMountPointW("E:\\")`
- `DefineDosDevice` 只定义进程命名空间设备名，不再用于盘符分配

### 2.2 attach 标志与盘符策略绑定

```
preferred_letter.is_some() → PERMANENT_LIFETIME | NO_DRIVE_LETTER（禁系统分配，强挂指定）
preferred_letter.is_none()  → PERMANENT_LIFETIME（系统自动分配，读回实际字母）
```

### 2.3 卷枚举四要素（全部真机踩坑验证）

| 要素 | 正确写法 | 错误后果 |
|---|---|---|
| 卷名 | 去尾反斜杠 `\\?\Volume{GUID}` | 0x3 路径找不到 |
| desired access | 0 | GENERIC_READ 被卷拒绝 → VolumeNotFound |
| flags | 0 | FILE_ATTRIBUTE_NORMAL 不适用设备 |
| share | FILE_SHARE_READ\|WRITE | 文档 Physical Disks and Volumes 节要求 |

## 3. 排错方法论沉淀（本次 10+ 个真机问题的共性教训）

### 3.1 环境 vs 参数二分：diskpart 对照实验

磁盘层排错最有效的一步——**diskpart 底层同样调 CreateVirtualDisk**。用它对同一 parent 建差分盘：

```powershell
'create vdisk file="C:\...\dp-test.vhd" parent="D:\1.vhd"' | diskpart
```

- diskpart 成功 → 环境（SMB/文件/格式）OK，问题收敛到**我们自己的参数**
- 一次实验排除所有环境假设，不猜

### 3.2 手写 FFI 布局必须实测对照（layout_probe）

编译期断言可能"自洽但错误"（断言自己算的偏移）。V1 结构 `parent_path` 我算 48、实测 40——多塞的 `_pad2` 让 CreateVirtualDisk 把 `sector_size` 后 4 字节当指针读。**V1/V2 的 padding 规则不同（SectorSize 结束 40 恰 8 倍数 / PhysicalSectorSize 结束 44 需 pad），不能照抄**。工具：mingw 交叉编译 C 程序打印真实 `offsetof`。

### 3.3 诊断日志 > 静默失败

`volume_has_disk` 原本静默返回 false——全靠加诊断日志（每卷打印 CreateFile/IOCTL 失败码）才定位到"所有卷 0x3"这一决定性证据。**静默吞错是排错的最大敌人**。

### 3.4 API 语义差异不可想当然

- `GetVirtualDiskPhysicalPath` **无**"传 NULL 探测大小"语义（不同于 GetModuleFileName）→ 单次调用 + MAX_PATH
- `CreateVirtualDisk` access mask 与参数版本**强绑定**：V1 用 CREATE(0x00100000)、V2 必须 NONE
- `FindFirstVolume` 返回卷名带尾斜杠，`CreateFile` 打开卷**去尾斜杠**（但 GetVolumePathNamesForVolumeNameW 用带尾斜杠）——同一路径不同 API 要求不同，查文档别猜

# GameVHD 边界情况审计（2026.8.8）

> 状态：三方评审合并稿（2026-08-08；代码审计 by Sisyphus，设计矩阵 by GPT-5.6-SOL MAX，盲区审查 by Claude Opus 4.8）
> 定位：**边界补充，不是设计推翻**——现有 VHD 实现（差分盘 + 外部状态库 + gvhook）是已验证的核心功能，本文只补"真实使用会踩但设计时没想到"的场景
> 关联：`docs/GameVHD_Runtime_实施计划.md`、`docs/GameVHD_DXVK集成设计.md`、`docs/2026.8.8_GameVHD沙箱Saga复盘.md`
> 演进：本项目功能持续演进（用户明确"不排除明天又出新功能"），本文作为活文档维护，新功能落地时同步补边界

## 0. TL;DR（先给结论）

- **现有实现的核心设计是自洽的**（差分盘写覆盖、外部状态库、hive 隔离、Job 生命周期、崩溃回滚），不做推翻性改动。
- **三方共识别出 40+ 个未覆盖边界**，其中最危险的 5 个共性：**要么静默击穿隔离边界，要么造成不可逆数据损坏**。
- **最优先补的 3 个**（高性价比）：
  1. 并发启动互斥锁（防止双开同一游戏损坏状态）
  2. cleanup 覆盖残留 VHD 挂载（当前只清 hive + 状态机）
  3. SMB 凭据不再经命令行/日志明文传递
- **GameAtlas 后端集成**：本审计的边界多数在后端拼装 manifest / 配置下发时同样适用（见 §5）。

## 2. 代码实证边界（Sisyphus 读代码发现）

以下均有代码证据，非推测：

| # | 边界 | 代码证据 | 严重度 |
|---|---|---|---|
| C1 | **多实例并发无锁**：同一游戏被双击/重复启动时，无互斥机制，差分盘/hive/box.json 竞态 | `run.rs`/`process.rs` 无 mutex/锁；`job_name(game_id)` 固定名但无获取检查 | 🔴 高 |
| C2 | **cleanup 不处理残留 VHD 挂载**：只清 hive + 状态机，残留盘符/Attach/差分盘/SMB 靠"后续事项" | `cleanup.rs:8` "残留 VHD 挂载与 state.json 宿主对账属后续事项" | 🔴 高 |
| C3 | **SMB 凭据走命令行**：`mount --user --pass` 参数，进程命令行对全机可见（WMI/ETW 审计） | `main.rs:85` Mount 命令接收 user/pass | 🔴 高 |
| C4 | **子进程注入无 exe 名排除**：游戏拉起的任何子进程（浏览器/更新器/crash reporter）都被注入 | `proc.c` 仅按位数判断，无名称/路径过滤 | 🟠 中 |
| C5 | **D3D12 直通判定依赖盘符推断**：bc64cca 修复后 hook 优先读 flags 编码盘符，但旧协议回退仍从 game_data_root 推断（外部状态根在 C: 时回退路径错误） | `file.c` `gvhd_file_game_drive()` 回退分支 | 🟠 中（已部分修复，回退路径待清理） |
| C6 | **box.json 位于差分盘（游戏可写区）**：游戏可改/损坏状态文件，恢复语义被破坏 | `boxfile.rs` BOX_FILE_NAME 在 GameData 下 | 🟠 中 |
| C7 | **盘符耗尽无回退**：26 字母用尽时 mount 失败无替代方案 | `disk.rs` 无 `\\?\Volume` / mountvol 回退 | 🟡 低 |

## 3. 设计维度边界（SOL MAX）

### A. 存储与挂载

| 场景 | 后果 | 严重度 | 建议 |
|---|---|---|---|
| SMB 会话身份混淆（已连接另一账户/别名指向同服务器） | `ERROR_SESSION_CREDENTIAL_CONFLICT`；清理误断他人连接 | 高 | 连接前核对现有会话服务器/共享/身份；连接记录带所有权 |
| NAS 休眠/重启在 VHD 挂载后 | 父盘 I/O 错误，游戏崩溃，差分盘不一致 | 高 | NAS 可用性作运行时依赖监控；不可恢复时受控终止并保留差分盘 |
| 基础 VHD 被替换/回滚/父子链不匹配 | 挂载失败或读到被篡改镜像 | 高 | 基础盘版本化不可变；attach 前校验 identifier+修改时间 |
| 空间/配额耗尽（差分盘+状态库同盘） | 部分保存、hive 损坏 | 高 | 启动前空间预留检查 + 运行中低水位告警 |
| 挂载后卷被外部卸载/盘符被改 | 后续写入落到新卷，宿主数据破坏 | 高 | 运行中绑定卷 GUID 持续校验，失配即停止 |
| 差分盘位于移动盘/云同步/FAT | 拔盘/同步冲突损坏 | 中 | 仅允许本地 NTFS/ReFS，记录卷序列号 |
| 盘符耗尽 | 无法启动或误用已有盘符 | 中 | 明确失败；兼容场景用卷 GUID/目录挂载点 |

### B. 路径与文件

| 场景 | 后果 | 严重度 | 建议 |
|---|---|---|---|
| 路径多形态（`\\?\`/卷 GUID/`\Device\`/UNC/短名/SUBST） | 纯字符串前缀匹配被绕过 | 高 | 匹配前归一化到规范形态，按对象身份决策 |
| 相对路径/`RootDirectory` 句柄/`.`/`..`/尾随空格 | 重写逃出 GameData | 高 | 解析根目录句柄 + 最终规范路径 |
| 超长路径（>MAX_PATH） | 固定缓冲区截断/内存越界 | 高 | 全链路 UTF-16 动态缓冲区，支持 `\\?\` |
| junction/symlink/OneDrive 接管 | 路径检查后跳转宿主；重置跟随链接删宿主数据 | 高 | 重解析点显式策略：禁止跨边界链接，handle-relative |
| 游戏写基础盘区域（VHD 根/安装目录） | 写绕状态库，"重置"是假象 | 高 | 明确游戏盘可写模型：预定义可写目录或纳入覆盖层 |
| 游戏写 ProgramData/Public/自定义绝对路径 | 宿主污染，重置不完整 | 高 | 运行跟踪建立持久化路径清单，未授权写点重定向或拒绝 |
| 规则表超 32 条 | 静默漏规则→宿主写入 | 高 | 参数块带 ABI 版本+长度校验，超限失败不截断 |
| 只拦 NtCreateFile/NtQueryDirectoryFile | 打开/属性/重命名/删除/硬链接入口绕过 | 高 | 审计 NtOpenFile/SetInformationFile 等完整 API 面 |
| 非 ASCII 用户名（中文） | ANSI 转换乱码，规则失效 | 中 | 全链路 UTF-16，禁止 ACP 回退 |
| `%TEMP%` 在其他盘/自定义 | 临时文件泄漏 | 中 | 运行时读实际 TEMP/TMP 动态生成规则 |

### C. 注册表

| 场景 | 后果 | 严重度 | 建议 |
|---|---|---|---|
| hive 损坏/掉电 .LOG 未回放 | RegLoadKey 失败，回落真实 HKCU 污染宿主 | 高 | 失败**拒绝启动**，绝不回落真实注册表 |
| 卸载时句柄占用 | hive 常驻 HKU，重置无效 | 高 | 进程树全退后卸载；失败进 pending 重试 |
| 游戏写 HKLM/服务/COM | 宿主持久污染，重置不干净 | 高 | HKLM 写默认拒绝或虚拟化 |
| HKCU 等价入口（HKU\<SID>/native/RegOpenCurrentUser） | 只匹配文本 HKCU 可绕过 | 高 | 所有预定义句柄归一化到同一逻辑 hive |
| 32 位 WOW64 双视图 | 一侧写真实 HKCU | 高 | 32/64 视图共同决策，同规则 ABI |
| RegLoadKey 缺特权（非提权） | 注册表隔离整体失效 | 高 | 启动时检查 SeRestore/SeBackup 特权 |
| 多实例共享 hive 文件 | 并发写损坏 | 高 | 每实例独立 hive + 独占 |

### D. 进程与注入

| 场景 | 后果 | 严重度 | 建议 |
|---|---|---|---|
| 注入失败后进程悬挂/未 hook 运行 | 逃逸写宿主 | 高 | 失败即 TerminateProcess，绝不 resume 未确认 hook |
| 子进程未注入（helper/更新器/浏览器） | 子进程写宿主 | 高 | 子进程执行前识别+挂起+注入+握手，否则阻止 |
| 游戏创建服务/驱动（EAC/BattlEye） | SYSTEM 上下文完全逃逸 | 高 | 检测反作弊组件，明确"此类游戏不保证隔离" |
| 游戏提权（UAC/runas） | 高完整性进程难注入且有宿主写权 | 高 | 游戏用受限令牌运行，阻断 elevation |
| Job handle 被继承/可打开 | KILL_ON_JOB_CLOSE 不触发 | 高 | 未命名 Job + 不可继承句柄 + 显式 TerminateJobObject |
| 杀软/受控文件夹拦截注入 | DLL 加载失败无提示 | 高 | DLL 签名 + 预检 + 可诊断错误 |
| Hook 安装晚于首次文件访问 | 早期访问逃逸 | 高 | 主线程 resume 前完成 hook，覆盖最早入口 |
| CREATE_BREAKAWAY_FROM_JOB | 子进程脱离管理 | 中 | Job 禁止 breakaway |
| 直连 syscall 绕过 | NT API hook 无效 | 中 | 认知边界：明确不支持此类游戏或更底层方案 |

### E. 生命周期与状态

| 场景 | 后果 | 严重度 | 建议 |
|---|---|---|---|
| box.json 只表达三态且位于差分盘 | 状态回滚 clean ≠ 资源已清理 | 高 | 宿主受保护位置权威运行日志（运行 GUID/卷/进程时间） |
| 崩溃在"资源已建"与"状态已写"之间 | 恢复不知道哪些资源存在 | 高 | 每步资源获取/释放写临时文件+原子替换 |
| 游戏可改 box.json | 诱导错误清理 | 高 | 状态元数据不在游戏可写区；严格 schema+校验 |
| 新启动/清理/恢复并发 | 旧清理终止新进程 | 高 | 跨进程互斥 + 运行 generation |
| 先写 clean 后释放资源 | 残留物理资源但状态"干净" | 高 | clean 只在所有释放验证完成后写 |
| 重启/休眠/注销期间挂载清理 | 状态不一致 | 高 | 下次启动只读盘点 + 幂等恢复 |
| 磁盘号/盘符/PID 被系统复用 | 清理错对象 | 高 | 匹配 VHD 唯一 ID/卷 GUID/进程创建时间 |

### F. 外部状态库

| 场景 | 后果 | 严重度 | 建议 |
|---|---|---|---|
| 游戏名含非法字符/保留名 | 建目录失败/路径穿越 | 高 | 目录名用稳定 ID 哈希，不用显示名 |
| 同名游戏/版本/渠道冲突 | 状态串扰 | 高 | 命名空间含发行者+ID+格式版本+用户 SID |
| 状态根只读/配额满/受控文件夹 | 首次保存失败；危险实现回落真实目录 | 高 | 启动前全操作预检，失败拒绝启动不回落 |
| 重置时进程未退出 | 半删损坏 | 高 | 重置前独占锁+确认进程全退 |
| 状态根在游戏盘/被重定向源内 | 重写循环/递归删除 | 高 | 创建配置时按卷 GUID/文件 ID 检查重叠 |
| 状态根被替换为 junction | 重置破坏任意宿主目录 | 高 | handle-relative + 不跟随 reparse point |
| 仅删外部 GameData 但 hive/差分盘残留 | "重置"不完整 | 高 | 重置=跨文件/注册表/差分盘原子 generation 切换 |
| 换机器/卷不同 | 启动失败或状态泄露 | 中 | 逻辑配置按机器解析，验证卷身份 |

### G. 凭据与安全

| 场景 | 后果 | 严重度 | 建议 |
|---|---|---|---|
| 凭据经日志/命令行/转储泄露 | 明文落盘，全机可见 | 高 | 日志脱敏 + 凭据管理器/DPAPI + zeroize |
| `net use` 会话对全宿主可用 | SMB 会话泄露给其他进程 | 高 | 私有会话隔离，游戏退出即断 |
| 用户态 hook 可被直连 syscall 绕过 | 不构成安全边界 | 高 | **明确威胁模型**：隔离承诺是"兼容性状态虚拟化"，不是安全沙箱 |
| junction/symlink 与提权清理组合 | 任意文件删除→本地提权 | 高 | launcher 不以提权遍历游戏可写树 |
| gvhook DLL 路径可写/搜索劫持 | 注入恶意 DLL | 高 | 受保护目录绝对路径 + 签名校验 |
| 尾部 manifest/box.json 被篡改 | 注入恶意 DLL/挂载恶意盘 | 高 | manifest 签名 + 运行时元数据受保护 |
| handle 继承给游戏 | 游戏持有资源阻止清理 | 高 | 默认 bInheritHandles=FALSE |
| 状态库/hive/差分盘 ACL 过宽 | 同机其他账户读取/篡改 | 高 | 按当前用户 SID 收紧 ACL |

## 4. 高频盲区（Claude 补充，题面外 ⊕）

| 盲区 | 后果 | 严重度 | 建议 |
|---|---|---|---|
| 游戏经 Shell API（SHGetKnownFolderPath）取目录 | 绕过基于路径前缀的 hook | 高 | Hook 覆盖 Shell/Known Folder API 或在返回值上再重定向 |
| 8.3 短名别名绕过长路径匹配 | 安装器用短名访问漏匹配 | 中 | 归一化短名→长名；或禁 8.3 生成 |
| 硬链接/ADS/设备路径 | 绕过前缀式规则 | 中 | 统一路径归一化（含 `file:stream`） |
| 孤儿 VHD 崩溃后仍 attached/开机自动重挂 | 下次盘符/文件被占 | 中 | 启动时枚举本项目 VHD 强制清理；关闭自动挂载 |
| AV/BitLocker 对 VHD 加锁/延迟 | attach 误判失败 | 中 | 差分盘目录加 AV 排除；重试+指数退避 |
| 编排器崩溃时 Job 句柄关闭语义 | 误杀游戏或游戏成孤儿 | 中 | 崩溃恢复按实际进程树状态决策 |
| pending 永久卡死累积 | 资源越积越多，重置失效 | 中 | pending 记录重试次数/年龄，超阈值告警 |
| 状态库在 OneDrive/云同步目录 | 同步锁争用+隐私+重置触发云删 | 中 | 检测并劝阻，默认放非同步位置 |
| 凭据驻留内存未清零 | 转储/内存扫描可提取 | 中 | 使用后立即清零 |

## 6. 最危险的 5 个未覆盖边界（三方共识排序）

| 排名 | 边界 | 共性 | 最低处置标准 |
|---|---|---|---|
| 1 | 用户态 hook 可被直连 syscall/未注入代码绕过 | 静默击穿"隔离"承诺 | 明确威胁模型；不可信代码用 VM/Windows Sandbox |
| 2 | 子进程/服务/提权逃逸 Job 与注入 | 进程在清理后继续运行并写宿主 | Job+注入握手为放行前置；服务/提权默认拒绝 |
| 3 | 父盘失配/运行中父盘 I/O 中断 | 静默损坏+存档全丢 | 基础盘版本化不可变；attach 前强校验 |
| 4 | 路径别名/Shell API/重解析点绕过 | "看似隔离实则逃逸" | 全路径归一化 + 重解析点显式策略 |
| 5 | SMB 凭据宿主级暴露 | NAS 访问权限溢出 | 凭据管理器 + 私有会话 + 日志脱敏 |

## 7. 建议实施优先级（性价比排序）

```text
P0（本周，低成本高收益）:
  1. 并发互斥锁（C1）——命名 mutex 按 game_id，第二实例明确报错
  2. cleanup 扩展覆盖残留 VHD（C2）——枚举本项目 VHD 按路径标识清理
  3. SMB 凭据改凭据管理器（C3）——mount 不再吃命令行 user/pass

P1（下个迭代）:
  4. box.json 权威状态外置 + 运行 generation（E）
  5. 子进程 exe 名排除清单（C4）
  6. 路径归一化模块（B：\\?\/卷 GUID/短名/重解析点）

P2（按功能演进）:
  7. HKLM 写策略（拒绝/虚拟化）
  8. 反作弊组件检测与"不保证隔离"声明
  9. 状态库命名空间含用户 SID（多用户）
  10. manifest 签名
```

## 6. 关键协议备忘（Go 代理移植时的对照表）

### 6.1 线协议（与 TS/Rust 字节级兼容）

```
客户端→代理: [op][ch][reserved=0][payload]
  op=1 OPEN:   payload=[proto u8][port u16 LE][host cstring]
  op=2 CLOSE:  payload 空
  op=3 DATA:   payload=原始字节
代理→客户端:
  op=3 DATA:   payload=原始字节
  op=4 CLOSED: payload=[reason u8]
reason: 0=normal 1=bad_proto 2=limit 3=connect_fail 4=bind_fail 5=io_error
proto:  1=UDP 2=TCP
channel 0 保留（控制/心跳）；max_channels 默认 64
```

### 6.2 配对（5 步，HTTP :47989）

1. `GET /pair?uniqueid&devicename&updateState=1&phrase=getservercert&salt&clientcert(hex PEM)` → `plaincert`(hex PEM)
2. `&clientchallenge=` AES-ECB(随机16B) → `challengeresponse` → 解密得 [server_response(32)][server_challenge(16)]
3. `&serverchallengeresp=` AES-ECB(SHA256(server_challenge || cert_signature || client_secret)) → `pairingsecret`(16+256) → RSA-SHA256 验签 server_secret + 比对 expected
4. `&clientpairingsecret=` client_secret || RSA-SHA256(签名) → paired=1
- AES key = SHA256(salt || pin)[:16]，AES-128-ECB 无填充
- 任一步失败 → `GET /unpair?uniqueid=` 清半配对态
- 成功 → 缓存主机证书 `hosts/<addr>.cert.pem`；身份 `pairing/{client_cert.pem,client_key.pem,unique_id.txt}`

### 6.3 NvHTTPS（mTLS :47984）

- 客户端身份 = 配对身份；RootCA = 缓存的服务器证书（自签无 SAN → InsecureSkipVerify + 手动 pin）
- `GET /applist?uniqueid&uuid` → `<App><ID><AppTitle><IsHdrSupported>`
- `GET|POST /launch?...mode=WxHxF&rikey&rikeyid&surroundAudioInfo...` → `sessionUrl0`；400 → 重试 `/resume`
- surroundAudioInfo：stereo=196610 surround51=65543 surround71=65799

### 6.4 TLS（串流端口自签）

- ECDSA P-256，CN=GameAtlas Streaming，10 年，SAN=localhost/127.0.0.1/::1
- 持久化 `data/streaming/server.crt|key`；Chrome 首次需手动信任

## 7. 已踩过的坑（避免重复）

1. **TCP relay 顺序执行死锁**：readLoop 同步阻塞在 conn.Read 时 writeLoop 永不运行 → 必须双 goroutine 并发（已修，tcp_relay.go）
2. **outFrames 关闭竞态**：relay 的 CLOSED 回调与 closeAll 并发，向已关 channel 发送 panic → outMu 互斥 + outClosed 标记（recover 不够，race detector 仍报）（已修，session.go）
3. **RSA 签名哈希模式**：Rust openssl 的 Signer/Verifier 默认 SHA256 前缀哈希，对应 Go 必须 `rsa.SignPKCS1v15(key, crypto.SHA256, hash(msg))`，不能传 0（NoHash）（已修，pairing.go）
4. **sanitizeDeviceName 对齐**：Rust 映射非 ASCII→`_`、空格→`+`，Go 需同款（已修）
5. **权限配置 last-match-wins**：opencode.json 的 permission 对象里 `*:ask` 放最后会覆盖前面的 allow（已修 ~/.config/opencode/opencode.json，external_directory + bash 白名单已生效）
